USES / 工具箱

工具不是收藏，
而是工作方式的外壳。

开发数据写作发布

这不是一份追逐新工具的清单。这里记录的是目前真正进入工作流、反复使用，并且知道为什么选择的东西。

LAST REVIEWED / 2026.07
01

WEB & PUBLISHING

网站与发布

  • Python + Flask保持后端结构直接，适合个人内容系统。
  • SQLite单机博客的数据足够轻，备份和迁移也简单。
  • Gunicorn + Nginx分别负责应用进程和公网请求入口。
  • SSH Tunnel公开阅读，私人编辑；后台不暴露在公网。
02

DATA & MODELING

数据与建模

  • Python清洗、验证、建模和可复现脚本的主工具。
  • CSV + JSON一个面向表格与人工检查，一个保留机器可读证据。
  • 质量报告记录重复、冲突、异常和未知组合，而不是只交付结果。
  • 基线 → 优化先证明简单方法成立，再增加模型复杂度。
03

DATABASE & RELIABILITY

数据库与可靠性

  • SQL Server用于事务、锁、存储过程和并发控制实验。
  • pyodbc连接 Python 测试脚本与数据库业务过程。
  • 压力测试把“不超卖”等业务规则变成可重复验证的不变量。
  • 约束兜底应用逻辑负责协调，数据库约束阻止最坏结果。
04

WRITING & DELIVERY

写作与交付

  • Markdown正文保持可读、可迁移，也方便版本记录。
  • 中文导出层内部字段服务计算，中文表头服务最终阅读。
  • UTF-8 BOM让中文 CSV 能被 Excel 直接正确打开。
  • RSS不依赖平台推荐，让更新可以被主动订阅。
